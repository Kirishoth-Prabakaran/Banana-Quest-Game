# Banana-Quest-Game
# 🎮 Game Project

A web-based game developed using React, Node.js, Express.js, Supabase, and Banana API.

The project follows a separate frontend and backend architecture to keep the code organized, maintainable, and scalable.

## ✨ Features

- 🎮 Interactive gameplay
- ⚛️ Modern frontend built with React and Vite
- 🛠️ Backend powered by Node.js and Express.js
- 🗄️ Supabase integration for database services
- 🔌 Banana API integration
- 📱 Responsive user interface
- 🔐 Environment-based configuration for sensitive credentials

*Features will be updated as development progresses.*

## 🧰 Tech Stack

| Technology | Purpose |
|---|---|
| React | Frontend user interface |
| Vite | Frontend development and build tooling |
| Node.js | Backend runtime |
| Express.js | Backend API and server-side logic |
| Supabase | Database and backend services |
| Banana API | External API integration |
| JavaScript | Application development |
| Git & GitHub | Version control |
